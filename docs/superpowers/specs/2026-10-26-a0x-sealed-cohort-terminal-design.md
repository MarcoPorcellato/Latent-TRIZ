## Approaches

Using calibration targets as a fallback is rejected: it changes the evaluation boundary and defeats split separation. Merely loosening the parent parser is rejected: it hides the selection bug. The approved approach combines a prospective sealed cohort, early public-only admission, and explicit failure-terminal convergence. An optional policy marker is rejected by Astra because it would silently admit legacy policy.

## Failure contract

The scientific frontier describes verified progress, not successful publication or cleanup. Failure production records the failing stage separately and chooses a conservative frontier from the verified lifecycle state. A target-read failure remains scientifically `failed`, with frontier `analysis` and diagnostic `TARGET_READ_FAILED`; no statistical claim is created.

A child may emit execution `completed` for an independently verified, successfully cleaned-up `sealed_failure`. The parent may accept that wire only with exact source/pair/authorization bindings, an allowed failure outcome/frontier tuple and the exact package reference, followed by its existing independent package and postflight verification. Scientific positive/null/non-interpretable outcomes still require the `sealed` frontier and all existing material-evidence checks. No failure is promoted to a statistical null.

Extend the result schema/semantic validator only to the already defined child frontier vocabulary. Asset capture follows the explicitly asset-bearing scientific outcomes, not frontier membership alone. Keep failure assets private. Preserve fail-closed behavior for malformed terminals, contradictory outcome/frontier tuples, missing packages, identity/hash drift and cleanup failures.

## Verification and non-goals

Use synthetic temporary fixtures with disjoint calibration/sealed IDs. Prove early rejection before claim/permission/model/target access; exercise the real failure producer, child serializer, parent parser and package verification rather than only hand-written wire fixtures. Keep OS/process/model boundaries injected; never execute CCP, Docker, a real model, tokenizer or target. No network, commit, regeneration, Gate A/B/C or publication is authorized.
